# Product: NecroText

NecroText is a Teletext revival for the Kiroween 2026 hackathon, category Resurrection. Teletext (Ceefax, Oracle) was a text broadcast service that died with analogue TV in 2012. NecroText brings it back as a static web app.

- Audience: hackathon judges, retro tech fans, people who remember page 100.
- Tone: dry British broadcast, with a quiet haunted streak. Never gore.
- The haunted layer must stay useful: page 666 is a real diagnostics page, 667 reads today's headlines.
- Static hosting on GitHub Pages. No server, no accounts, no tracking.
- Zero runtime dependencies. Do not add npm packages.
- Student solo project: prefer small, readable code over clever code.
