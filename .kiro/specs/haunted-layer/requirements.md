# Haunted Layer: Requirements

The haunted layer must be useful, not only spooky.

1. THE System SHALL provide page 666 "The Dead Letter Office" that lists each data source as ALIVE, STALE or DEAD with its age, item count and last error.
2. WHEN a source fetch failed, THE page 666 SHALL show it as DEAD with the error text.
3. WHEN a source is a bundled sample or older than six hours, THE page 666 SHALL show it as STALE and THE source pages SHALL show CACHED in the header.
4. THE page 666 SHALL have a second subpage listing stories that lack a summary or a link.
5. THE System SHALL provide page 667 "The Oracle" producing a fortune from the current headlines, stable for a calendar day.
6. THE System SHALL provide page 888 "Ghost Subtitles" showing whispers derived from headlines.
7. THE System SHALL provide an unlisted page 013 with a concealed message.
8. WHILE the page is displayed, THE UI SHALL occasionally spell a whisper on row 22 derived from words on screen.
9. WHEN the user presses S, THE UI SHALL toggle seance mode: red tint, faster flicker and heavier text corruption.
10. THE glitch function SHALL NOT alter dimensions, control codes, rows 0, 22 or 23, or rows below double height rows, and SHALL be deterministic for a given seed.
